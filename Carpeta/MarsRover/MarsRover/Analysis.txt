https://www.codurance.com/katas/simple-mars-rover

Observable behavior:
- control the rover over the plateau

Input:
- an array of commands
- dimensions of the plateau
- position and orientation of the Mars rover

Output:
- position and orientation of the Rover

Preconditions:
- plateau is bigger than 1x1
- invalid commands are ignored
- commands array can be empty

Smaller behavior:
- Mars rover starts at 0, 0 facing north.
- Mars rover receives an array of commands
- For each command Mars rover performs an action
    - `M`: Moves 1 unit forward
    - `R`: Rotates right N->E->S->W
    - `L`:  Rotates left N->W->S->E
- If Mars rover is at the edge of the map it wraps around the plateau.
- Returns the position and orientation of the Mars rover at the end of the array of commands.

Examples:
State: (x, y, q), Commands: "" => x:y:q
State: (0, 0, N), Commands: "M" => 0:1:N
State: (0, 0, E), Commands: "M" => 1:0:E
State: (1, 1, W), Commands: "M" => 0:1:W
State: (1, 1, S), Commands: "M" => 1:0:S
State: (0, 0, N), Commands: "R" => 0:0:E
State: (0, 0, E), Commands: "R" => 0:0:S
State: (0, 0, S), Commands: "R" => 0:0:W
State: (0, 0, W), Commands: "R" => 0:0:N
State: (0, 0, N), Commands: "L" => 0:0:W
State: (0, 0, W), Commands: "L" => 0:0:S
State: (0, 0, S), Commands: "L" => 0:0:E
State: (0, 0, E), Commands: "L" => 0:0:N
State: (0, 0, N), Commands: "MM" => 0:2:N
State: (0, 0, N), Commands: "M" "M" => 0:2:N
State: (0, 0, S), Commands: "M" => 0:9:S
State: (0, 0, W), Commands: "M" => 9:0:W
State: (9, 9, N), Commands: "M" => 9:0:N
State: (9, 9, E), Commands: "M" => 0:9:E
